# ADR 0001: Record architecture decisions

- **Status:** Accepted

## Context

Design decisions in this project need to be explainable later, in reviews and interviews.

## Decision

Every significant decision gets a short ADR in `docs/adr/`, numbered in order, with context,
decision and consequences.

## Consequences

Decisions are traceable from RFC to code. Superseded ADRs are kept and marked as such.
